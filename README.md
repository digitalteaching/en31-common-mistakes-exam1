# Exam 1: Common mistakes (Englisch, EN31)

Fehlerbesprechung der ersten Klausur für den Beamer, zu H. G. Wells,
*The New Accelerator* (Summary und Discussion). Teil 1 behandelt die häufigsten
Sprachfehler, Teil 2 den Aufbau von Summary und Discussion; nach jedem Abschnitt
eine Übung mit aufdeckbaren Lösungen. Alles auf Englisch. Eine einzige
HTML-Datei, keine Installation.

**Direkt öffnen:** https://digitalteaching.github.io/en31-common-mistakes-exam1/

## Bedienung

- Pfeiltasten, Leertaste oder Presenter: nächster Schritt bzw. nächste Lösung.
- Lösungen lassen sich auch einzeln anklicken.
- A−/A+ ändert die Schriftgröße, „Full screen“ für den Beamer.
- Adresse mit `#5` öffnet direkt Folie 5.

## Technisches

- Eine Datei: `index.html`, kein Build, keine Abhängigkeiten, läuft auch offline.
- Es werden keine Daten übertragen; nur die Schriftgröße bleibt im Browser gespeichert.
